Regle :
Un const placé avant l'étoile (const int*) protege la variable désignée : on ne peut pas la 
modifier a travers ce pointeur (*a = 5  est refusée) , mais le pointeur peut etre déplacé vers une 
autre variable ( a= &y est acceptee).
Un const placé apres l'étoile ( int* const) protege le pointeur lui-meme : il doit toujours designer
la meme variable et ne peut pas etre deplace ( b =&y refusee) , mais on peut modifier la variable designee à
travers lui(*b = 5 est acceptee)
Avec const des deux cotes (const int* const c ) , les deux sont protegés : on ne peut ni ecrire à travers c , ni le deplacer.
